Enabling Logi Report Logging

← Back to app

This tool analyses log files produced by Logi Report Server. Before you can use it, logging must be enabled and configured in Logi Report. This page walks you through that setup.

Official reference: Configuring Logi Report Logging System ↗

For this tool: use INFO in production. Use DEBUG or ALL only when actively troubleshooting — these produce very large files quickly.

Option 1 — Configure via Server Console (UI)

  1. Open Server Console → Administration → Configuration → Log
  2. Select the log category you want to enable (e.g. Engine)
  3. Set Log Level to INFO (or higher if needed)
  4. Set Appender to RollingFile
  5. Set File Name — leave default or use an absolute path
  6. Set Max File Size (e.g. 50MB) and Max Backup Index (e.g. 5)
  7. Save and restart the Logi Report Server

Repeat for each log type you want to collect.

Option 2 — Configure via LogConfig.properties

Edit <install_root>\bin\LogConfig.properties. Example for Engine log:

log4j.logger.Engine=INFO, EngineAppender

log4j.appender.EngineAppender=org.apache.log4j.RollingFileAppender
log4j.appender.EngineAppender.File=C:/LogiReport/Server/logs/Engine.log
log4j.appender.EngineAppender.MaxFileSize=50MB
log4j.appender.EngineAppender.MaxBackupIndex=5
log4j.appender.EngineAppender.layout=org.apache.log4j.PatternLayout
log4j.appender.EngineAppender.layout.ConversionPattern=%m [%t][%p][%d{dd MM yyyy HH:mm:ss,SSS}]%n

Repeat the block for each log type, substituting the category name:

Logger nameAppender name (convention)File name
EngineEngineAppenderEngine.log
DHTMLDHTMLAppenderDHTML.log
AccessAccessAppenderAccess.log
ErrorErrorAppenderError.log
EventEventAppenderEvent.log
DebugDebugAppenderDebug.log
PerformancePerfAppenderPerformance.log
DumpDumpAppenderDump.log
Performance note: Do not use %C, %F, %L, or %M in the ConversionPattern — they use reflection and significantly slow down logging.

Daily rotation instead of size-based

log4j.appender.EngineAppender=org.apache.log4j.DailyRollingFileAppender
log4j.appender.EngineAppender.DatePattern='.'yyyy-MM-dd

After editing, restart the Logi Report Server for changes to take effect.

Command-line startup flags

These flags override LogConfig.properties at server start:

FlagEffect
-vDebugEngine → file at INFO level
-vErrorEngine → file at ERROR level
-logallAll loggers → INFO level
-log[:fileName]Engine → specified file at DEBUG level

Recommended setup for this tool

Enable at least these log types at INFO level for the most useful analysis:
Engine, DHTML, Error, Access, Dump
  • Use RollingFile with MaxFileSize=50MB and MaxBackupIndex=3 to prevent disk pressure
  • Collect logs during a representative workload (minutes to hours depending on traffic)
  • Upload all .log files together — this tool correlates events across files by timestamp
  • If your server uses Organisations, each organisation has its own log subfolder — collect from all relevant subfolders
